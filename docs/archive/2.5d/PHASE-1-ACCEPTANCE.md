# Phase 1 — Hybrid Art Direction Acceptance & Closure

**Branch:** `phase-1/hybrid-art-direction`  
**Status:** CLOSED — direction established; visual execution moves to Phase 2

## Objective

Establish the creative and production direction for an original 2.5D animated narrative system, using broad reference qualities such as expressive character-led storytelling, graphic clarity, clean compositions, and fast visual communication.

## Closure decision

Phase 1 is closed at the **direction and principles level**. It establishes what the project is trying to make and the constraints Phase 2 must respect. It does not claim that the final visual identity has been approved or that the current SVG board demonstrates the target quality.

The first-pass SVG board was reviewed and rejected because it looked like a basic diagram rather than polished animation artwork. It is not an approved reference, must not be used as an art-quality target, and must not be used to lock the character, palette, or environment design.

## Accepted decisions

- [x] The project uses a hybrid 2.5D direction: illustrated 2D characters and environments arranged in layered 3D space.
- [x] Character-led storytelling, expressive acting, readable silhouettes, visual clarity, and purposeful motion are the core creative priorities.
- [x] All characters, props, environments, compositions, and graphic assets must be original.
- [x] The workflow should combine 2D artwork/cutout animation with depth, camera, lighting, and selective 3D elements where they materially improve the shot.
- [x] Quality is judged from finished artwork and rendered motion at delivery size—not from documentation or placeholder diagrams.
- [x] The production toolchain remains open until a practical visual/animation test validates it.

## Explicitly not frozen

These are Phase 2 look-development decisions, not hidden approvals:

- Final protagonist appearance, silhouette, clothing, and proportions.
- Final palette, linework, shading, and texture treatment.
- Environment illustration style and detail level.
- Camera projection, scene scale, parallax strength, and depth conventions.
- Character rig structure, asset format, and exact software/toolchain.

The earlier protagonist and palette descriptions are disposable concepts only. Do not treat them as approved designs.

## Phase 2 handoff

Phase 2 begins with finished visual proof, not pipeline implementation:

1. Develop a distinctive original protagonist with a coherent silhouette and expressive face.
2. Produce a polished character sheet: front/three-quarter/side views, expressions, and useful acting poses.
3. Create at least one finished interior and one finished exterior environment.
4. Stage a short 5–10 second scene using layered 2.5D depth, motivated camera movement, and selective 3D elements only where useful.
5. Review the result at final delivery size against the quality standards.
6. Revise the art direction based on the rendered evidence, then freeze the visual contract and choose the production toolchain.

## Phase 2 exit gate

Do not declare the visual system production-ready until the character, environments, and short motion test demonstrate consistent quality. A technically working pipeline is not sufficient if the artwork looks generic, flat, unfinished, or visually inconsistent.

## Final status

**Phase 1 is complete and closed.** Remaining visual design and technical validation are intentionally assigned to Phase 2. This is a deliberate phase boundary, not a claim that the rejected board is finished artwork.
