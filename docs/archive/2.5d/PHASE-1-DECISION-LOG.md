## Phase 2 decision rule

Prefer the simplest workflow that produces consistently polished, expressive scenes. Do not select tools or freeze asset schemas before the protagonist sheet, environment samples, and short motion test have passed visual review.

Changes to locked Phase 1 principles require an explicit decision-log update. Phase 2 may freely revise the provisional character, palette, linework, environment treatment, and implementation choices based on visual evidence.
